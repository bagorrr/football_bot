# Triage Labels

The skills use five canonical triage roles. This file maps those roles to the labels used in GitHub Issues.

| Label in mattpocock/skills | Label in this repository | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer must evaluate the issue |
| `needs-info` | `needs-info` | Waiting for information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an autonomous agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or intervention |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill refers to a canonical triage role, use the corresponding GitHub label from this table.
